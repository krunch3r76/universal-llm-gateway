# Configuration Reference

All configuration files, environment variables, and paths.

## Config Files

| File | Purpose | Generated by |
|---|---|---|
| `~/.gateway/stargate.yaml` | Master Stargate config | `./manage` (first start, never overwritten) |
| `~/.gateway/nodes/<host>.env` | Per-node: NODE_ID, MODEL_PATH, federation keys | `./manage` |
| `.env.local` | Local env: MODEL_PATH_ROOT | Manual |
| `~/.rag/config.yaml` | RAG service watcher config | Manual |
| `config/stargate_config.yaml` | Default Stargate config template | Source |

## Environment Variables

### Stargate

| Variable | Purpose | Default |
|---|---|---|
| `STARGATE_CONFIG` | Path to Stargate config YAML | `config/stargate_config.yaml` |
| `STARGATE_MODE` | Override federation mode | From config |
| `STARGATE_UNIX_SOCKET` | Unix socket path (Edge mode) | — |
| `STARGATE_ENABLE_TCP_MONITORING` | Enable TCP monitoring on 9997 | false |
| `FEDERATION_KEY` | Edge federation API key | — |
| `FEDERATION_KEY_EDGE_*` | Per-edge federation keys | — |
| `DEBUG_EVENT_PERSIST` | Enable event persistence | true |
| `DEBUG_EVENT_PERSIST_DIR` | Event persistence directory | `/tmp/stargate-events` |
| `PIPELINE_EVENT_PERSIST` | Pipeline event persistence | true |
| `DATA_DIR` | Request snapshot base directory | — |
| `LOG_DIR` | Log base directory | `/tmp/logs/universal-stargate` |

### Gateway

| Variable | Purpose | Default |
|---|---|---|
| `LOG_DIR` | Log base directory | `/tmp/logs/universal-llm-gateway` |
| `MODEL_PATH` | Model file directory | — |

### RAG

| Variable | Purpose | Default |
|---|---|---|
| `GATEWAY_URL` | Embedding endpoint URL | `http://localhost:9999` |

## Stargate Config Structure (stargate.yaml)

```yaml
federation:
  mode: master                      # master | remote | edge
  stargate_id: master-localhost

  local_edge:
    socket_path: "/tmp/universal-protocol/edge-localhost.sock"
    stargate_id: edge-localhost
    api_key: "${FEDERATION_KEY_EDGE_LOCALHOST}"

  remotes:
    - stargate_id: relay-jupiter
      url: "http://jupiter:9999"
      api_key: "${FEDERATION_KEY_JUPITER}"

routing:
  scoring:
    weights: { resource_fit: 0.4, staleness: 0.3, stability: 0.3 }
  sticky_models: []                 # model IDs that pin to one gateway

request_queue:
  timeout: 120                      # queue_timeout seconds
  upstream_retry_timeout: 90        # retry timeout for upstream errors

token_management:
  enabled: true

pipelines:
  search_paths:
    - pipelines
    - pipelines.local
  output_dir: /tmp/logs/universal-stargate/pipeline_summaries
```

## RAG Config (~/.rag/config.yaml)

`WatchDirectory` fields: `path`, `extensions`, `recursive` (default `true`), `chunk_tokens` (optional int — overrides default 512-token chunk size for that directory; use 1024 for ebooks), `exclude` (optional filename globs matched with `fnmatch`; excluded files are skipped by startup, reconcile, and hot-reload indexing).

```yaml
watch_directories:
  - path: /mnt/torus/projects/universal-llm-gateway/docs/architecture
    extensions: [md]
    recursive: true
  - path: /mnt/torus/projects/universal-llm-gateway/docs/vision
    extensions: [md]
    recursive: true
  - path: /mnt/torus/projects/universal-llm-gateway/docs/engram
    extensions: [md, txt]
    recursive: true
  - path: /mnt/torus/projects/universal-llm-gateway/tasks/journal
    extensions: [md, yaml]
    recursive: true
  - path: /mnt/torus/projects/universal-llm-gateway/docs/reference
    extensions: [pdf, epub]
    chunk_tokens: 1024
    exclude: [CORPUS_MANIFEST.md]
    recursive: true
```

Ebook files (PDF, EPUB) belong in `docs/reference/`. They are indexed at 1024 tokens/chunk and retrieved via `--scope ebooks` in `scripts/consult`. EPUB extraction uses `ebooklib` + `BeautifulSoup`; PDF uses `pymupdf4llm`.

## Log Paths

| Service | Path |
|---|---|
| Stargate (host) | `/tmp/logs/universal-stargate/universal_stargate.log` |
| Gateway (container) | `/golem/logs/gateway/gateway.log` |
| Edge Stargate (container) | `/golem/logs/stargate/universal_stargate.log` |
| Workers (container) | `/golem/logs/workers/` or `/tmp/process_ipc/{model_id}` |
| RAG | `/tmp/logs/universal-rag/rag.log` |

## Event Paths

| Source | Path |
|---|---|
| Stargate events | `/tmp/stargate-events/current.jsonl` |
| Pipeline events | `/tmp/pipeline-events/current.jsonl` |
| RAG events | `/tmp/rag-events/current.jsonl` |
| Edge Stargate events | Container: `/tmp/stargate-events/current.jsonl` |

## Socket Paths

| Socket | Purpose |
|---|---|
| `/tmp/universal-protocol/edge-localhost.sock` | Master ↔ local Edge |
| `/tmp/universal-protocol/*.sock` | IPC sockets |
| `/tmp/process_ipc/*.sock` | Worker process IPC |

## Port Semantics

| Port | Accessible to | Purpose |
|---|---|---|
| 9999 | Clients, agents, curl | Sole external endpoint (Stargate) |
| 9998 | Container-internal only | Gateway (inference) |
| 9997 | Host (optional) | TCP monitoring |
| 8100 | Host | RAG service |
