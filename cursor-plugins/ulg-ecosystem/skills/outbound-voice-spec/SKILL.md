# Outbound Voice Spec

`¬ instruct(model_identity)` · `⇒ specify(output_artifact)`.

claude.ai resists identity assignment ("you are my pen", "act as the signer") — persona negotiation without changing the draft. Describe the **message the operator will send**, not the **seat writing it**.

Load **`prose-discipline`** for register craft, antecedents, and AI-trite bans. This skill binds **task shape, material boundaries, engagement, and deliverable gate** before the first sentence.

## Hard gate (activation)

`outbound_draft_in_turn ⇒ visible_OUTBOUND_SPEC_block_precedes_draft_in_same_turn`

A draft body emitted without a filled **OUTBOUND SPEC** block above it in the same turn — or an explicit same-thread turn-ref citing an already-bound OUTBOUND SPEC — is **malformed**. Continuity `## Skills` listing this slug is ambient awareness only; it does **not** activate the gate. Next-pickup / next_acts that commission outbound must read: `Bind OUTBOUND SPEC (Use outbound-voice-spec + prose-discipline) → draft <artifact>`.

## Transmit

A message in the signer's name stays a draft until the operator says submit. That word comes before any form post, mail, fax, or email.

**Deliverable outcomes** (OUTBOUND SPEC `Deliverable:`):

| Outcome | When |
|---|---|
| `body` | Spec complete; facts attested; send-ready one message |
| `HOLD_SEND(reason)` | Load-bearing proof/role gap is better **solicited** than asserted; dual-audience hole-to-plug risk (see a:38524; full anticipate matrix → `hypothesize-simulate` / matter runbook — not expanded here) |
| `[NEED: …]` only | Non-blocking gap that does **not** change the ask — one bracketed question **inside** an otherwise send-ready body; never a menu of options |

Critical gaps (would change standing, objective, or a claim the recipient will treat as fact) ⇒ **`HOLD_SEND`**, not a half-baked body with `[NEED:]`. Ask and record the gap before any sentence depends on it.

**HOLD / wake guard:** If the target matter, mailbox, or wake carries a `HOLD` pin (e.g. pharmacy Outlook until Kaywan raises it) or the turn is a `BRIDGE_WAKE` / push-wake that does not commission outbound ⇒ **refuse draft generation**. Wake ≠ send authorization.

## FACT ceiling (claim guardrail)

tAIm voice governs **conviction and cadence of attested propositions**. It never licenses:

- unattested causal links or bridging arguments between attested facts
- epistemic hedges from `no-silent-inference` (`"This may suggest…"`, `"One possibility is…"`) **inside** the outbound body
- tidy arguments the operator did not supply

`prose-discipline` cause-effect connectives (`but`/`so`/`because`) may join **attested** steps only. Graph recall and silent-inference discipline apply **before** material enters OUTBOUND SPEC — not as freestyle inside the send body.

## OUTBOUND SPEC (fill before drafting)

Every field describes the **artifact** or **attested facts**, never the model. Blank field ⇒ **forbidden to invent** for that dimension.

```text
OUTBOUND SPEC
Signer (first person inside the message only): <name>
Recipient / thread: <who reads it>
Objective (one line): <what this message must accomplish>
Material attested by signer (exhaustive — do not add facts):
  - (from operator / voice note)
  - (from recall/user — list each promoted graph fact here; unmarked recall is not material)
Standing limits (signer must not claim or imply):
  -
Channel / format rules: <e.g. SMS sentence-initial caps; portal char limit; none>
Voice anchor (optional — 1–3 sentences cadence only; if blank and Signer=Kaywan → tAIm standing register):
Objective priority: if conflict, <objective> beats <new angle>
Deliverable: body | HOLD_SEND(reason) — one outcome; no preamble; no options; no commentary after
```

**Recall promotion:** `Standing biography ON` and `recall(op="matter")` are session orientation. Facts used in the draft must be **listed under Material attested** (tag `(from recall/user)`). Unlisted graph noise is forbidden. Ghostwrite (signer ≠ operator): mark operator biography `SOURCE: … — context, not material`.
