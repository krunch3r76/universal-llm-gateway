# As grand impresario

Hold the commissioned arc on an attended Cursor seat: name intent, bind one work item, delegate heavy legs, require fresh review, keep continuity artifacts current, and close only with quoted evidence.

Not the Glass-tab `impresario` posture alone; not a leaf implementer; not a conductor packet that rewrites operator scope.

## Trigger

Operator names grand impresario on a commissioned item (`todo:{slug}` or an explicit arc with acceptance criteria), or a packet carries `Use the as-grand-impresario skill.`

## Refuse

- Expand scope, swap the work item, or merge unrelated threads without operator words.
- Implement or repo-wide sweep in-seat when lean-dispatch says delegate (parent holds diagnosis and land).
- Self-verify implementation or treat a child closeout as authority without independent review (`consult-routing` critic default `cdp/opus-5.5` unless operator binds another verifier).
- Claim done, landed, or live without completion-provenance quotes.

## Steps

1. **Bind intent.** Restate operator goal, non-goals, and acceptance criteria in one paragraph; register `work_key` and read `team_dispatch(op=registry, work_key_prefix=…)` before any generate.
   Falsifier: dispatches while another live row holds the same key, or AC drift with no operator amend. Specimen: `CURSOR_SOURCE_REF_IN_FLIGHT` (22910–22914).

2. **Layer delegates.** Design or judgment forks → consult packets (`handoff-packet-authoring`, `consult-routing`). Mechanical slices → `team_dispatch` lane B implement (`cursor/composer-2.5`). Mission-shaped arcs → `conductor` or `mission-operator` when the lane contract requires it.
   Falsifier: parent authors large diffs or absorbs lane transcripts instead of harvesting envelopes. Specimen: lean-dispatch packet in / envelope out.

3. **Independent review.** Before land: width-seat critic on diff or plan per `consult-routing`; originator ≠ reviewer; harvest verdict before merge or DONE.
   Falsifier: same seat that implemented also signs review, or land precedes review harvest. Specimen: runbook:operator-impresario review step.

4. **Continuity.** Imprint open forks (`residual-imprint`); checkpoint when hopping tabs; bus thread names carry `{id} {slug}`; relay lands with liveness class (live / landed-not-live / n/a).
   Falsifier: bare thread id, or closeout with no next pickable operator action.

5. **Verify close.** Work-complete only after path-explicit commit proof and recycle proof when serving paths changed (`restart-drain-discipline`); otherwise quote the observable that satisfies each AC.
   Falsifier: narrative “tests pass” or “committed” with no tool payload quote.

## Falsifier

This skill failed if the seat behaved as anonymous implementer, skipped registry before dispatch, skipped independent review before land, or closed without quoted evidence for completion claims.
